6 / 12
Deliverable R2

Restocking Recommendations

The data needed to automate purchase order recommendations already exists in Meridian's system. We connect the pieces.

Inputs

Current stock levels · Demand forecasts (28% coverage, heuristic fallback for the rest) · Backlog priority items · Operator budget ceiling

Algorithm

Calculate shortfall per item · Rank by backlog priority then shortfall/cost ratio · Filter to budget ceiling · Surface top recommendations

Output

Ranked purchase order list · Item, quantity, estimated cost · Remaining budget · Warehouse-level filtering

Built in Vue 3 Composition API, integrated with the existing filter system. Fully tested via Playwright before delivery.
